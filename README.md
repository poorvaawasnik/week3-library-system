# Week 3 – Library Management System

## 📌 Project Overview
This is a simple **Library Management System** built using **HTML, CSS, and JavaScript**.  
It allows users to add, display, and remove books from a list. The data is stored in the browser using **LocalStorage**.

---

## 🚀 Features
- Add books with title, author, and category
- Display all added books in a table
- Delete books from the list
- Stores data in LocalStorage (persists after refresh)
- Clean and simple UI
